# MLQ goal cover variants

Six individual opaque WebP cover illustrations, 1600 x 1200, each below 250 KB. These supplement the original pack.

Copy the assets directory into your project. Ensure your existing pubspec.yaml flutter.assets list includes assets/images/ui/covers/.

```dart
Image.asset(
  'assets/images/ui/covers/goal_academic_boy.webp',
  fit: BoxFit.cover,
)
```

Use the original 4:3 aspect ratio for full compositions. Review narrower crops individually, especially the three-person Social covers. No changes to your application code have been made.

Files:
- goal_academic_boy.webp
- goal_academic_girl.webp
- goal_health_boy.webp
- goal_health_girl.webp
- goal_social_boys.webp
- goal_social_girls.webp

Generated using the built-in image generator and exported to WebP.
